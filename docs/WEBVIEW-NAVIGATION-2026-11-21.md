# 通用 WebView 导航（2026-11-21）

## 行为

- 独立应用内网页页的左上返回和 Android 系统返回行为一致：有网页历史时返回上一页，没有上一页时关闭网页页并返回调用方。
- 顶栏刷新重新加载当前页；顶栏「×」明确关闭网页页，即使还有网页历史也返回调用方。
- 复制链接、外部浏览器、清理缓存继续在溢出菜单；调用方传入 `editUrl` 时保留编辑操作，顶栏空间不足则移入菜单。
- 不改专用登录 WebView 或嵌在业务页标签中的 WebView；不改网页安全提示、Cookie 注入或远端白名单。
