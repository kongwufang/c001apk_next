# 隐私说明：日志与数据（2026-11-08 更新）

> 对应 App 首次启动引导的第 4 步「查看隐私协议」，以及「设置 → 高级 → 日志」。

## 一句话总结

**本 App 不上传任何日志或诊断数据。** 日志只写在你手机本地，开关由你自己控制，
随时可以导出成 zip 或一键清空。服务器只会收到匿名的、与你个人无关的少量请求。

## 一、本机日志（唯一的日志能力）

`设置 → 高级 → 日志`：

| 功能 | 说明 |
|---|---|
记录日志（开关）| 默认关闭；打开后才写文件 |
日志级别 | VERBOSE / DEBUG / INFO / WARN / ERROR |
日志模块 | 14 个模块可选（net / feed / card / ui …），全不选 = 全部 |
查看最近日志 | 在 App 内按模块筛选查看 |
导出 App 日志（zip）| 打包到本地并分享（你自己决定发给谁）|
清空 App 日志 | 删除全部本地日志 |

**落盘位置**：App 私有目录 `files/app_logs/`，按天分文件、单文件 2MB 滚动、最多保留 3 天。
**脱敏**：写入前会把 `token / cookie / ssaid / uid / username` 等字段替换成 `***`。
**导出物**：zip 内的 `device.txt` 只含品牌、型号、SDK、本 App 版本、日志级别、模块列表、丢弃计数 —— **不含任何账号标识**。

## 二、服务器能收到什么

本 App 打到自建服务器（`service.houlangs.cn`）的只有这几类请求，且都是**匿名**的：

| 接口 | 内容 | 用途 |
|---|---|---|
`/c001apk/heartbeat/` | 版本号、机型、系统版本、随机设备标识 | 判断你是否在线（不发推送，纯统计）|
`/c001apk/notice/` | 同上 | 取侧栏公告/升级卡 |
`/c001apk/update/stable.json` | 版本号 | 检查更新 |
`/c001apk/gates/`、`/blocklist/` | 版本号 | 云端开关与黑名单 |

**服务器不会收到**：
- 你浏览了哪些帖子、搜索了什么、给谁点赞
- 你的账号密码、Cookie、token
- 你的照片、文件、通讯录、位置
- 任何形式的崩溃日志、诊断包、App 日志（这条是本次更新的重点：该能力已**删除**）

## 三、已删除的能力（2026-11-08）

按社区反馈，以下功能与代码已从 App 中彻底移除：

```
· 用户体验改善计划（接受服务器下发的诊断/事件请求）—— 已删除
· 诊断上报（崩溃摘要 + 设备快照 + 日志尾部的上传）—— 已删除
· 匿名举报联盟（含举报入口的上报通道）—— 已删除
```

⇒ 现在服务器**没有任何渠道**能让 App 上传日志或诊断数据。

## 四、你可能关心的几个问题

**Q：那「检查更新」会不会上传设备信息？**
A：只带版本号，服务器据此返回最新版本号与下载链接。

**Q：日志里会不会有我的账号？**
A：不会。落盘前已脱敏（`uid` / `username` / `token` / `ssaid` / `cookie` 全部打码）。

**Q：怎么彻底关掉日志？**
A：`设置 → 高级 → 日志 → 记录日志` 关掉；再点「清空 App 日志」删掉已写的文件。

**Q：怎么确认我说的是真的？**
A：本项目是开源的（`github.com/kongwufang/c001apk_next`），可以用 `grep -r "DiagReport\|ReportAlliance"` 之类的方式验证代码里确实没有上传路径。
